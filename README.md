# Otis — Stretchable-Face Portfolio

React + Vite + TypeScript portfolio, prepared for GitHub Pages at:
https://muhammadagungf.github.io/portfolio/

## Required image assets

The interactive portrait needs 14 WebP files in `public/faces/`:
`base.webp`, `l_left.webp`, `l_right.webp`, `x_cross.webp`, `x_tongue.webp`, `x_shock.webp`, `x_laugh.webp`, `x_skeptic.webp`, `x_whistle.webp`, `x_smug.webp`, `x_dizzy.webp`, `g_grimace.webp`, `g_ouch.webp`, and `g_squish.webp`.

The image archive has not yet been added. Add those files before enabling deployment; otherwise the face artwork will not load.

## Local development

```bash
npm install
npm run dev
```
